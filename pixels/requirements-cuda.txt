# PLATE pixels: the `cuda` extra. RENDER BOX ONLY.

# RTX 5090 = sm_120, needs torch built for CUDA 12.8+; install only on the box, never in tests or bootstrap.
# Nothing in this repo installs this file (tests, scripts/bootstrap.ps1 and `make setup` all skip it), and
# the service runs in stub mode without any of it. On the box, from the repo root, in two steps:
#
#   1. torch + torchvision from the CUDA 12.8 wheel index (the default PyPI wheel on Windows is CPU-only):
#        uv pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
#   2. the rest of this file from PyPI:
#        uv pip install -r pixels/requirements-cuda.txt
#
# A later plain `uv sync` removes these packages again; use `uv sync --inexact` to keep them.
